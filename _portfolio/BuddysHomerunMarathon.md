3D modeling, animation, and engine pipeline:

<ul>
  <li>3D Model Generation and Cleanup: Used Meshy.ai to generate the initial 3D character models, then imported them into Blender to clean up the mesh geometry and fix the UV maps.</li>
  <li>Character Rigging and Animation: Rigged the cleaned-up 3D models using Mixamo so the characters could use animations from the large Mixamo animation library.</li>
  <li>Web 3D Physics and Rendering: Used Three.js to handle 3D rendering and physics directly inside the web browser.</li>
  <li>Custom Runtime Development Engine: Alongside the batting game mode, we built a custom development engine where users can upload and run their own scripts, models, textures, and assets to build and edit their own games live at runtime.</li>
</ul>
